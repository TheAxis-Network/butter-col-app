    About this app
    
      
    butter-col-app is an example app for butter-col, a service-worker web proxy by Axis Network. It is plain HTML, CSS and JavaScript with no build step, served by butter-col's own OpenResty server with --site public.
    
      
    How it works
    
      
      
        
    1. ButterController (from /butter/controller.mjs) registers /butter/sw.js with scope / and reads /butter/config.js, which also issues the session cookie.
      2. 
        
    2. A target such as https://example.com/ becomes a proxy URL under /butter/go/, encoded with the configured codec.
      3. 
        
    3. The service worker intercepts every request the proxied page makes and hands it to the active transport. The built-in butter transport sends it to /butter/fetch with the target in X-Butter-URL.
      4. 
        
    4. The Lua server checks the target (DNS pinning, private-address guard), adds cookies from the session's jar, and lets nginx stream the upstream response back.
      5. 
        
    5. The service worker rewrites HTML, CSS and JavaScript so the page keeps working from this origin, and injects the client runtime.
      6. 
      
    
      
    Be careful
    
      
    Like every same-origin proxy, all proxied sites share this origin, and butter-col doesn't emulate CORS or SameSite yet. Don't log in to anything important through it, and don't expose this server to others without authentication. The full list is in the project's known issues.
